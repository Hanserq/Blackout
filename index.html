Security Architecture & Specifications

Formal cryptographic guarantees designed for air-gapped confidential communications.

Cipher Suite

AES-256-GCM

Symmetric authenticated encryption provides both confidentiality and cryptographic tamper-proofing. Each session derives a unique 96-bit initialization vector (IV).

Key Hardening

PBKDF2 (100,000 Rounds)

Passwords are stretched with 100,000 iterations of HMAC-SHA-256 and a 16-byte cryptographically secure random salt, thwarting GPU/ASIC rainbow table attacks.

Entropy Reduction

GZIP Deflation Stream

Payload data is compressed before encryption, flattening plaintext entropy patterns and minimizing the carrier footprint for seamless concealment.

Steganography

Dual Carrier Concealment

Conceal payloads within standard PNG ancillary chunks (bLoK) or append via binary trailer markers to PDF, JPEG, and documents while preserving original viewing capability.
